# 对 6 个工具的 鼠标样式做优化

1. 画笔工具 采用 画笔图标，画笔的笔尖是触发点
2. 其余工具采用统一的自定义箭头，选择工具只显示箭头，其他工具在箭头右下角显示小图标；触发中心均在箭头的箭尖处
   1. 选择工具，采用与其他工具一致的自定义箭头，不带右下角小图标
   2. 方框工具，箭头右下角有一个小方框形状
   3. 箭头工具，箭头右下角有 一个三条线段构成的简易箭头形状，它45度角指向右上方
   4. 文字工具，箭头右下角有一个小的输入文字的光标形状
   5. 序号工具，箭头右下角是小序号，这个序号的样式和真实序号样式相似，但规格要小得多
3. 箭头+小图标的使用紧凑的布局
4. 六个工具的光标统一缩放为原尺寸的 3/4，箭尖或画笔笔尖的触发位置保持不变
5. 所有箭头右下角的小图标整体向右移动 1pt，箭尖触发位置保持不变
6. 方框、箭头和文字工具进入文字编辑状态后，整个画布仍显示当前工具光标
