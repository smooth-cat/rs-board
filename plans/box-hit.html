方框标签布局规则：方框本体可以相邻/交叉/包含，只有标签联合避让

当前实现不再禁止方框本体互相贴住、交叉或包含。重排只作用于可见方框标签：从本次操作影响到的冲突连通组出发，批量求解每个标签的实际锚点。

1. Preferred vs Actual

preferred_label_anchor 保存默认或手拖偏好；label_anchor 保存求解后的实际显示位置。自动避让改 actual，不覆盖 preferred。

两个锚点

2. 连接组：before/after 图边并集

求解器用变更前后两张冲突图的边集并集，从操作方框和 seed 开始 BFS；解除冲突后标签自然回偏好。

BFS 范围

3. 冲突源：只看方框世界

障碍来自方框本体和其他方框标签。非方框元素忽略；隐藏标签不参与放置，但它所属方框本体仍然阻挡标签。

障碍规则

4. 8 条轨道：先滑动，再换轨

Top / Bottom / Left / Right 各有 Inside / Outside。候选先投影 preferred 和 current，再加合法区间两端；下面用典型场景说明避让优先级。

轨道排序
轨道代价 0同 edge 且同 side，优先沿边滑动找空位。
轨道代价 1同 edge 换 Inside / Outside。
轨道代价 2换到其他边，再按固定轨道序稳定收敛。
同轨滑动优先 Top Outside 被邻框或标签挡住时，先沿同一边水平滑到空区，不立即换 Inside 或换边。
同边换内外 同边外侧没有可用空区时，优先尝试同 edge 的 Top Inside / Bottom Inside 等内外侧候选。
必要时换边 同边内外都冲突时才换到其他 edge，并用固定轨道序稳定决胜，避免每次求解跳到不同边。
回到偏好 障碍移开后，before + after 连通组仍会把受影响标签一起求解，标签可回到 preferred。
边缘接触也算冲突 标签和本体或其他标签之间必须保留 offset 安全间距；刚好贴边也视为冲突。
标签之间联合避让 两个可见方框标签互相占位时，会进入同一个连通组一起求解，而不是只把当前操作标签单独挪开。

5. Beam / 降级流程

最多 32 个可见标签进入同一轮重排；beam width 128，中间状态上限 4096。正常路径只接受零碰撞解。

兜底

6. 编辑器接入：同一批次，预览提交一致

创建、粘贴、删除、移动、缩放、拖标签、文字/字号/线宽、层级都会触发同一套重排；一次 batch 形成一次 revision / undo。

编辑链路
核心边界 方框本体可以相邻、交叉、包含；标签必须在画布内，并尽量避开其他方框本体和可见方框标签。
连接图 节点是方框；边来自本体接触/相交、标签压到对方本体、标签互相压到。连接检测同时看 actual 和 preferred 标签位置。
偏好保存 手拖标签时 preferred 和 actual 一起更新；自动重排保留 preferred，只改变 actual，便于冲突解除后回位。
