# 默认样式与工具颜色持久化方案

## Summary

- 在设置窗口中新增“默认样式”区域，用一个 5 项 tab 栏展示：`方框 / 箭头 / 文字 / 画笔 / 序号`。
- 设置页不提供颜色配置；默认颜色为红色，编辑器现有颜色选择保留。
- 每个工具独立持久化“最后一次主动选择的颜色”，应用级跨重启保存。
- 设置页保存的字号、边框/宽度、硬度只影响下次编辑会话中新建元素，不批量修改已有元素，也不改当前已打开会话。

## Key Changes

- 扩展 `Settings`，加入可序列化的工具默认样式配置：
  - `方框`: 字体 `36 pt`，边框 `8 px`
  - `箭头`: 字体 `24 pt`，边框 `8 px`
  - `文字`: 字体 `36 pt`
  - `画笔`: 宽度 `8 px`，硬度 `0%`
  - `序号`: 字体 `24 pt`
  - 每个工具颜色默认 `RED #FF3B30`
- 设置页 tab 内容使用现有合法预设下拉框：
  - 字号沿用现有字号预设并显示 `pt`
  - 边框/宽度沿用现有线宽预设并显示 `px`
  - 硬度沿用现有硬度预设并显示百分比
  - 不展示颜色控件
- `EditorController` 新建时从 `Settings` 注入工具样式，而不是全部使用同一个 `ToolStyle::default()`。
- 保留编辑器工具栏颜色选择：
  - 选中已有元素时，工具栏显示该元素颜色
  - 用户主动从色板选色时，同时修改该元素并记录为对应工具的最后颜色
  - 只是选中或进入编辑已有元素，不更新工具默认颜色
- 仅颜色在编辑器内自动写回持久化设置；字号、线宽、硬度在编辑器内调整仍只影响当前会话/元素，不自动改设置页默认值。

## Interfaces / Data

- `Settings` 增加工具样式字段，并保持旧 `settings.json` 可读：旧文件缺少新字段时补齐上述默认值。
- 新增/复用一个设置层的数据结构表达五个创建工具的默认样式；不为 `Select` 工具展示或保存默认样式。
- 应用保存设置仍走现有 `settings_draft -> apply_settings -> settings.json` 流程。
- 编辑器主动选色时向应用层发出“工具颜色已更新”的事件或等价回调，由应用层更新 `Settings` 并保存。

## Test Plan

- `Settings::default()` 校验五个工具默认值与方案一致，颜色均为红色。
- 旧版 settings JSON 缺少样式字段时能正常加载，并补齐默认样式。
- 设置页保存后重新打开新编辑会话，新建方框/箭头/文字/画笔/序号使用对应默认字号、宽度、硬度。
- 当前已打开编辑会话在设置保存后不被静默重置。
- 编辑器中主动改某工具颜色后，关闭并重启应用，新会话该工具继续使用最后颜色。
- 选中已有元素只显示元素颜色，不写入工具颜色；主动选色才写入。
- 已有元素不会因为设置页保存默认样式而被批量修改。

## Assumptions

- “边框”按现有 `width_px` / stroke width 实现。
- 序号内部仍可保留现有线宽默认 `8 px`，但设置页只展示字号。
- 颜色不能在设置页手动配置，但编辑器色板继续作为“最后一次使用颜色”的来源。
