# Bundled Font Assets

`NotoSansSC-Regular.otf` is bundled as the raster-rendering fallback for Simplified Chinese text.

- Source: Google Noto CJK / Noto Sans SC Regular
- Upstream: https://github.com/notofonts/noto-cjk
- License: SIL Open Font License, Version 1.1

The font is included unmodified.
